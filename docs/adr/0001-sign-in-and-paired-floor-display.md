# Sign-in locks random browsers; a paired floor display does not

Two people use the full app, and the gym needs an unlocked screen. Signing in on a phone is both a lock (a random browser cannot open the app) and a persona (the app defaults to me). A paired floor display skips sign-in, runs the full app with no me, and logs results into the participant slots of the session on screen.

We rejected persona-only access (anyone with the URL can use the app, including API keys) and lock-everywhere (no gym screen without an account).
